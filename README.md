# 신촌 셔츠룸 정적 사이트

## 구현 기준

- 핵심 사용자: 신촌에서 당일 또는 야간 방문을 검토하며 위치·운영시간·이용 구성을 빠르게 확인하려는 성인
- 전환 목표: 전화 연결, 카카오톡 ID 복사, 텔레그램 연결
- 대표 검색 의도: `신촌 셔츠룸` 거래형·지역 탐색형
- 보조 검색 의도: `신촌 셔츠룸 위치`, `신촌역 셔츠룸`, `신촌 셔츠룸 주차`
- 공개 정책: 구체 가격표는 제외하고 방문 전 최종 금액 확인 안내만 제공

## 기존 사이트와 구분되는 점

1. 사진 중심 랜딩이 아닌 심야 라디오 편성표를 닮은 타이포그래피 중심 디자인
2. 역 합류형 홍대 사이트와 달리 실제 주소·출구·도보·랜드마크를 첫 화면부터 공개
3. 반복 카드 대신 시간 큐시트, 편성표, 도식화된 동선으로 정보를 구성

## 정보 구조

- `/`: 거래형 메인 랜딩. 운영·이용 구성·방문 순서·위치·FAQ·문의 수록
- `/location/`: 위치 탐색형 보조 페이지. 지하철·차량 동선과 주차 정보 수록
- 홈에서 위치 페이지로, 위치 페이지에서 홈과 문의로 상호 연결

## SEO·렌더링 전략

- 프레임워크와 외부 라이브러리 없이 핵심 콘텐츠를 정적 HTML로 제공
- 페이지별 고유 title, description, canonical, OG, Twitter 메타 적용
- 실제 공개 정보만 `NightClub`, `WebSite`, `WebPage`, `BreadcrumbList`, `FAQPage` JSON-LD에 반영
- `robots.txt`, `sitemap.xml`, 사용자용 404 포함
- 외부 폰트와 사진을 사용하지 않아 렌더 차단과 이미지 LCP를 최소화

## 모바일·접근성·측정 계획

- 모바일 첫 화면에서 위치·운영시간·전화/카톡을 바로 확인
- 44px 이상 터치 영역, 키보드 포커스, 본문 건너뛰기, 시맨틱 HTML, reduced-motion 지원
- 분석 도구는 동의·계정 정보가 없어 삽입하지 않음
- 추후 GA4를 연결할 경우 `phone_click`, `kakao_copy`, `telegram_click`, `map_open`, `not_found` 이벤트를 우선 측정

## 위험 요소와 배포 전 확인

- GitHub 사용자명과 저장소명이 달라지면 canonical, OG URL, sitemap, robots, 404 절대 경로를 함께 변경
- SVG OG 이미지는 일부 메신저에서 미리보기가 제한될 수 있어 배포 전 1200×630 PNG로 교체 권장
- 검색 순위는 콘텐츠 외에도 도메인 신뢰도, 색인 상태, 경쟁도, 외부 언급 등에 영향을 받으므로 보장할 수 없음
- 실제 외관·내부 사진을 확보하면 출처가 명확한 원본만 추가

## 검증 방법

1. 로컬 HTTP 서버에서 홈·위치·404와 모든 링크 확인
2. HTML validator 및 JSON-LD 파싱 확인
3. canonical·robots·sitemap의 운영 URL 일치 확인
4. 모바일 360px, 태블릿 768px, 데스크톱 1440px에서 가로 스크롤·CTA·포커스 확인
5. 배포 후 Search Console에 sitemap 제출하고 URL 검사를 통해 생성 HTML 확인
